### Architectural Domains:
- **`ui/` (148 files)**: Visual components, M3 responsive cards, data grids, error boundaries, and permission wrappers.
- **`compliance/` (157 files)**: Deterministic gatekeepers, append-only immutable logs, biometric step-up, and audit checks.
- **`interaction/` (67 files)**: Touch interaction mechanics, auto-scrolling focus positioning, dynamic balance calculators, and keydown interceptors.
- **`layout/` (32 files)**: Adaptive canonical layouts, GCP document auto-croppers, and viewport emulators.
- **`tokens/` (30 files)**: Material 3 design tokens (48dp touch bounds, HSL color schemes, typography hierarchy, elevation tiers).
- **`network/` (37 files)**: BigQuery streaming buffers, API gateway perimeter filters, Pub/Sub log streamers, and telemetry monitors.
- **`accessibility/` (5 files)**: High-contrast callouts, smart keyboard insets, touch target padding, and screen-reader accessibility tools.
- **`versioning/` (6 files)**: Context isolation, master data dictionary managers, and package lock monitors.
- **`models/` (2 files)**: Immutable view state data models and step catalog definitions.
